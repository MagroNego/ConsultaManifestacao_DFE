Importar XML

{% call guide('Importar XML') %}
  1. Selecione XMLs de NF-e emitidas pelo CNPJ configurado, eventos de cancelamento homologados ou ZIPs com subpastas.
  2. Clique em Importar dados e confira o registro do lote.

Limites: 100 MiB por envio, 250 MiB descompactados e 5.000 documentos. Chaves repetidas preservam os dados existentes; cancelamentos atualizam a situação.

O app guarda dados para relatórios. Obtenha o XML original no Synchro.

Alterar situação de notas

{% call guide('Alterar situação de notas') %}
  1. Informe uma nota ou chave por linha, até 100 notas.
  2. Se o número identificar mais de uma nota, use a chave de 44 dígitos.
  3. Preencha o motivo e escolha a ação.

A marcação é local e vale na Consulta, Emissão e novos relatórios. Remover a marcação manual não desfaz cancelamentos recebidos da SEFAZ.
